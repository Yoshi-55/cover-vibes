# cover-vibes （２）

## ジャケットから新しい音楽との出会いを**
CDショップでの「ジャケ買い」の体験をウェブで

MVP：ランダムでジャケットを表示 → Spotifyで試聴」の最小機能

---

## コンセプト
- ジャケットを見て新しい音楽を発見
- 「何を聴こう？」と迷っているユーザー向け
- MVPではシンプルにランダム表示とSpotify試聴

---

## 技術スタック
- **バックエンド**: Ruby on Rails 7
- **フロントエンド**: ERB, Turbo, Stimulus, Tailwind CSS, DaisyUI
- **API**: Spotify Web API
- **データベース**: 未使用（API直取得）
- **デプロイ**: Render

---

## MVP機能
1. **ジャケットランダム表示**
2. **ジャンル指定・ランダム検索**
3. **ジャケットクリックで詳細モーダル表示**
4. **Spotify埋め込みプレイヤーで試聴**
5. **Spotifyリンク表示**

---

## 使い方
1. トップページでジャンルを選択、または「ランダム表示」ボタンをクリック
2. ランダムに表示されたアルバムジャケットをクリック
3. モーダルでアルバム詳細・Spotifyプレイヤーを確認
4. Spotifyリンクでフル再生
